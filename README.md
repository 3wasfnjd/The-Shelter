# THE SHELTER — BUNKER 17

مشروع لعبة Escape Room ثلاثية الأبعاد تدور داخل ملجأ عسكري Stylized Low-Poly مصمم كـ Cutaway Diorama.

## الرؤية المختصرة

- غرفة واحدة رئيسية عالية الجودة بدل عدد كبير من الغرف.
- Web / Mobile: منظور Isometric ثلاثي الأبعاد مع شخصية قابلة للتحكم.
- Meta Quest VR: نفس الغرفة بالحجم الحقيقي بمنظور First-Person.
- AR: نفس الملجأ كمجسم Miniature Diorama تفاعلي يوضع على سطح حقيقي.
- أسلوب فني: Premium Stylized Low-Poly Military Survival.
- الألغاز: الطاقة → الضغط → الأدلة → لوحة التحكم → باب الخروج.
- نفس Game State ونفس Puzzle Logic عبر Web وVR وAR.
- الموديلات المرئية النهائية يجب أن تكون GLB/glTF فعلية، وليست مجسمات هندسية بدائية.
